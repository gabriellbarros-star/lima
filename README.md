# LógicaX — Desafio Mental

## Sobre o aplicativo
O **LógicaX — Desafio Mental** é um jogo educativo desenvolvido para exercitar o raciocínio lógico, a identificação de sequências matemáticas, a percepção de padrões e a atenção por meio de desafios interativos.

## Objetivo
Oferecer uma forma simples e divertida de praticar habilidades de lógica, acompanhando o progresso e a pontuação durante uma partida.

## Funcionalidades
- **Oito desafios** de múltipla escolha, com dificuldade progressiva.
- **Pontuação:** 10 pontos por acerto direto ou 5 pontos quando a resposta é obtida após usar uma dica.
- **Dicas:** opção para solicitar uma pista antes de responder.
- **Progresso da partida:** indicação do desafio atual e barra de progresso.
- **Feedback:** retorno visual após responder.
- **Resultados finais:** exibição da pontuação, quantidade de acertos e melhor recorde.
- **Reinício:** opção para jogar novamente.

## Tecnologias
O arquivo HTML fornecido indica uma interface construída em HTML, com estilos em `style.css` e comportamento em JavaScript em `script.js`. O projeto também referencia fontes do Google Fonts. Para executar todas as funcionalidades, esses arquivos precisam estar disponíveis no local esperado.

## Como executar
1. Coloque `index.html`, `style.css` e `script.js` na mesma pasta.
2. Abra `index.html` em um navegador atualizado, como Google Chrome, Microsoft Edge ou Firefox.
3. Clique em **Iniciar Desafio** e siga as instruções na tela.
4. Ao terminar, confira os resultados e selecione **Jogar Novamente** para iniciar outra partida.

**Importante:** o arquivo recebido nesta conversa foi `index.html`. Os arquivos `style.css` e `script.js` são referenciados pelo HTML, mas não foram incluídos no material recebido. Para que o aplicativo funcione e apareça com o estilo esperado, esses arquivos também precisam estar presentes.
